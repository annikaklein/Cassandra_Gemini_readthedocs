Installation
============

Requirements
------------

- Python 3.14 
- Jupyter Notebook / JupyterLab
- Packages: ``numpy``, ``scipy``, ``pandas``, ``matplotlib``, ``cmocean``, ``rasterio``, ``shapely``, ``pyproj``,
  ``scikit-learn``, ``earthengine-api``, ``geemap``
- For ``data_source = "gee"``: a Google Earth Engine account


Quick Start
-----------

1. Download ``CassandraGemini.ipynb``, ``SDB.py`` and ``parameters.py`` into one folder.
2. Install the packages above.
3. Open the notebook, set the configuration cell and run the cells from top to bottom
   (see :doc:`code`).
